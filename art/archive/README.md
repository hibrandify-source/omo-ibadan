# Archived district paintings

The painted district scenes that the game used before every district had a
walkable, code-drawn street. They're no longer served to players (this folder
sits outside `public/`), and are kept as reference for the painting update.

- `districts/*.jpeg.jpg`: the original paintings.
- `districts/opt/`: the resized WebP versions, plus `manifest.json`, which
  listed each scene's doors, NPC spots and gates in image coordinates.
