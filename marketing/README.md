# Omo Ibadan · social launch kit

Everything here is drawn from the game itself (same art kit), so posts match what players see.

## Files (`launch/`)

| File | Use |
|---|---|
| `01-cover.jpg` … `07-play-free.jpg` | First post: a 7-slide carousel, 1080×1350 (Instagram/Facebook portrait). `01-cover.jpg` also works alone as a single post. |
| `profile-picture.png` | Profile photo, 1080×1080. The sun-ring "O" stays inside the circle crop. |
| `cover-banner-1500x500.jpg` | X header and Facebook cover. |
| `logo-horizontal-light.png` / `-dark.png` | Logo with wordmark, for anywhere else. |
| `../brand/logo-mark.svg` | The mark as a vector, at any size. |

To change text or re-capture art: run the dev server on :3001, then `node marketing/tools/capture.cjs` (game art → `art/`) and `node marketing/tools/render.cjs` (`tools/posts.html` → `launch/`).

## Setting up the page

**Handle** (same everywhere): `@omoibadan.game`, `@omoibadangame` or `@myibadanlife` (if you move the site to myibadanlife). Pick the first one free on Instagram, TikTok and X.

**Name:** Omo Ibadan

**Bio (Instagram, under 150 characters):**
> Live your Ibadan life 🏠☀️ A free life-sim set in real Ibadan, 18 → 38. Born in Beere or Bodija? Play free, no download 👇

**Link:** the game. Use the home page, not /play, so new people see what it is first.

**Where:** Instagram and TikTok for reach, X for Ibadan Twitter, and a WhatsApp Channel. WhatsApp is where Nigerian friends actually share links.
